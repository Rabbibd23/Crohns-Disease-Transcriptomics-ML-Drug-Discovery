# Crohn's Disease ML-Based Drug Discovery

This repository provides the datasets, source code, computational workflows, analysis scripts, and supplementary materials associated with our study on machine learning-assisted drug discovery for Crohn's disease.

## GEO Datasets

The GEO datasets analyzed in our manuscript are listed below:

- GSE16879: https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE16879
- GSE66545: https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE66545
- GSE71730: https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE71730
- GSE112366: https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE112366
- GSE207022: https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE207022
- GSE48634: https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE48634
- GSE119600: https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE119600
