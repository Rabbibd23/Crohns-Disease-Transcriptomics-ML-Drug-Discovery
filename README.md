# Crohn's Disease Transcriptomics and ML-Assisted Drug Discovery

## Associated Manuscript

**Development of flexible workflows for exploring therapeutic targets and agents through transcriptomics analysis and their applications in Crohn’s disease for disclosing natural compounds as drug molecules**

This repository contains the data, source code, analysis scripts, computational workflows, and supplementary materials associated with our study on transcriptomics-guided therapeutic target identification and machine learning-assisted natural-product drug discovery for Crohn's disease.

The workflow integrates transcriptomic data preprocessing and harmonization, target identification, cheminformatics-based natural-product filtering, STAT3-specific ML-QSAR modeling, ligand preparation, molecular docking, decoy-based docking-score assessment, ADMET analysis, molecular dynamics simulation, and MM-GBSA analysis.
